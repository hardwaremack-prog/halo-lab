Why is the NPU usually at 0%?

The NPU is a low-power AI chip built for efficiency, not raw speed. Ollama, LM Studio and llama.cpp run models on the GPU, which is far faster for big models on this machine, so the NPU sits idle while you chat with them. That's normal.

To put the NPU to work, use AMD Lemonade Server (pick it at the top right) with a model marked NPU or Hybrid in Lemonade's model manager. Hybrid models read your prompt on the NPU and write the answer on the GPU. Windows Studio Effects (camera blur, eye contact) and some Copilot+ features also use the NPU, and they'll show up here too.

Setup

Halo Lab is the dashboard. The models run in an engine on this computer. Ollama is the easiest and works with every tab.

Engine addresses

1. Install Ollama (recommended)

  1. Download and install from ollama.com/download (Windows).
  2. It runs in the system tray. The dot at the top right turns green when Halo Lab can see it.
  3. Go to Model Library and press Download on a model. Qwen3 30B-A3B or gpt-oss 20B are great first picks: smart and very fast on this chip.

2. If the dot stays red

Ollama blocks web pages it doesn't recognize. Run Fix Ollama connection.bat from the Halo Lab folder once, or do it by hand in PowerShell:

setx OLLAMA_ORIGINS "*" then quit Ollama from the tray icon and start it again.

3. Give the GPU more memory

  1. Open AMD Software: Adrenalin Edition → Performance → Tuning and look for Variable Graphics Memory. (Menu names can shift between driver versions. The same setting is also in the BIOS as the UMA frame buffer size.)
  2. On a 96 GB EVO-X2, 64 GB is a good balance. Bigger lets you run gpt-oss 120B comfortably, but Windows needs at least 16 GB left over.
  3. Restart, then set the same number in Model Library → GPU memory budget.

Other engines

  1. LM Studio: in the Developer tab, start the server and turn on Enable CORS. Chat, Arena and Benchmark work. Download models in LM Studio's own Discover tab.
  2. AMD Lemonade Server: AMD's engine that can also use the NPU. Default address is already filled in above.
  3. llama.cpp server: start llama-server with the Vulkan build. It reports exact timings to the Benchmark tab.

Hardware monitor (CPU, GPU and NPU meters)

  1. Web pages can't read hardware sensors, so Halo Lab comes with a tiny helper, halo-monitor.ps1. It reads the same counters Task Manager uses and shares them only with this computer.
  2. Start everything with Start Halo Lab.bat. It opens the monitor in a small minimized window and then opens the dashboard. Closing that window stops the monitor.
  3. Seeing NPU activity needs Windows 11 24H2 or newer and AMD's NPU driver. If Task Manager's Performance tab shows an NPU, Halo Lab will too.

Speed tips for this chip

  1. MoE models fly here. Models like Qwen3 30B-A3B and gpt-oss only use a few billion "active" parameters per word, so they run 30–60+ tok/s. Dense 70B models are smart but crawl at around 4–6 tok/s.
  2. Bigger context windows use more memory and slow the first token. Use 8–16K unless you're pasting long documents.
  3. Plug in the power brick and use the machine's performance mode for best results.
